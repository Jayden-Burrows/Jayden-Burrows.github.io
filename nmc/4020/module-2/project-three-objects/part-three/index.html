Reflection

  1. Provide at least one prompt you used to build this case file.
    For this assignment, I used AI to generate the layout based off of the example prompt and the example website. From there, I prompted AI to make further changes to the content and styling. For example, here are two of the prompts I used to start the project:

    My prompts with Gemini: Chat Log

    My prompt with Claude: Chat Log

  2. What did you change after the AI output?

    I leveraged AI to make major modifications to the layout and JavaScript logic, which would have been time-intensive for me. From there, I made manual edits to make small adjustments such as adding valid images, adding an overlay over the smaller images, and removing/editing any content I didn't like.

  3. What did you learn about JS objects?

    My past coursework in Web Program had already given me experience with objects, but Part One of this project gave me a good refresher on some methods to manipulate the information inside them. Part Two of this project didn't really teach me much as I had a less hands-on role with the code.

  4. During this project, did you see AI as a shortcut, a collaborator, or something else?

    For me, AI was a shortcut in this project as it made a lot of the tedious parts of programming very quick, letting me focus on the general details of this project. I'm also not the best at web design (as you might tell from Part One of this project), so AI was an effective tool for creating a somewhat nicer page.

  5. After this project, what is a new boundary you would set for yourself OR a boundary you would remove when using AI?

    For me, I would try to set a clear baseline for AI in the future with visual mockups and starter code, so I can be more involved with the development process and ensure that AI can effectively assess my intentions. I would also limit the amount of programming that AI does, so I can learn the code myself.
