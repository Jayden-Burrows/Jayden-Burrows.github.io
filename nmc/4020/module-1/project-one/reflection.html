Reflection

How this project has enhanced reinforced my skillset

Image by Marcel Strauß on Unsplash

Starting this project, I chose the Solid State theme from HTML5 UP because I enjoyed the general color palette and the nice features it has for the navigation.

  • When you scroll, the navigation's background increases its opacity.
  • The menu button looks good at any size screen.
  • The menu has a slight layout animation as it comes into the screen.

The main issue I has was adjusting some of the template's styling because the original author had multiple stylesheets and each one had thousands of lines. However, I was able to condense the stylesheets into one and use the inspect tool to help me add/edit the styling in a way I liked.

I'm proud of a few small animations I added to the index. When you hover over "LEARN MORE", the link becomes underlined, and the icon's background color becomes lighter. When you hover over an article image, it zooms slightly. I'm most proud of the fact that I hosted this project on WordPress for free too. If you go to this page, I have a copy of this website hosted using infinityFree's free hosting and their plugin for WordPress. I also acquired a new domain from NameCheap for my GitHub website, so the url should become jayden-burrows.me instead of jayden-burrows.github.io.
