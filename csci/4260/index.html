1. Foundations & Course Scope

This course is not classical computer security (malware, viruses, network attacks). It focuses on security and privacy of AI/ML systems.

Core Modules

  • Information security: CIA triad, cryptographic building blocks.
  • Attacking AI systems: Adversarial examples, LLM jailbreaks.
  • Secure & private learning: Federated learning, homomorphic encryption.
  • Data privacy: Anonymization, differential privacy, privacy-preserving ML.

What Can Go Wrong (Beyond Accuracy)

  • Evasion attacks: Small perturbations cause misclassification.
  • Data poisoning: Corrupt training data.
  • Privacy leakage: Reconstruction, membership inference, attribute inference.
  • Data extraction: LLMs memorize and regurgitate training data.
  • Gradient inversion: Recover training data from shared gradients in FL.
  • De-anonymization: Netflix Prize linkage to IMDb.

Key idea: Data staying local does not mean data staying private. Federated learning keeps raw data on devices, but the updates (gradients/parameters) still leak information.

2. Mathematical Background

2.1 Linear Algebra

Vectors & Norms

  • L0 norm: # of non-zero elements.
  • L1 norm: \(\|x\|_1 = \sum |x_i|\) (Manhattan).
  • L2 norm: \(\|x\|_2 = \sqrt{\sum x_i^2}\) (Euclidean).
  • L∞ norm: \(\|x\|_\infty = \max |x_i|\).

Inner Product & Matrices

  • Inner product: \(\langle x, y \rangle = x^T y = \sum x_i y_i\).
  • Transpose: \((A^T)_{ij} = A_{ji}\).
  • Matrix product: \(C_{ij} = \sum_k A_{ik} B_{kj}\).
  • \(AB \neq BA\) in general.

2.2 Probability

Conditional Probability & Bayes

\[ P(A|B) = \frac{P(A \cap B)}{P(B)} \]

\[ P(A|B) = \frac{P(B|A)P(A)}{P(B)} \]

Expectation, Variance, Covariance

  • \(\mathbb{E}[X] = \sum x p(x)\)
  • \(\text{Var}(X) = \mathbb{E}[(X-\mu)^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2\)
  • \(\text{Cov}(X,Y) = \mathbb{E}[XY] - \mathbb{E}[X]\mathbb{E}[Y]\)
  • Independent \(\Rightarrow\) Cov = 0, but Cov = 0 does not imply independence.

Risk analysis: \(\text{risk} = \mathbb{E}[\text{loss}] = \sum_{\text{threats}} \text{loss} \times P[\text{threat}]\).

2.3 Calculus & Optimization

Derivative & Gradient

\[ f'(x) = \lim_{h\to 0} \frac{f(x+h)-f(x)}{h} \]

\[ \nabla f(x) = \left[\frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_p}\right]^T \]

Taylor Approximation

Second-order around \(x_0\):

\[ f(x) \approx f(x_0) + \nabla f(x_0)^T(x-x_0) + \frac{1}{2}(x-x_0)^T \nabla^2 f(x_0)(x-x_0) \]

Convexity

\(f\) is convex if:

\[ f(\alpha x + (1-\alpha)y) \leq \alpha f(x) + (1-\alpha)f(y) \]

For differentiable \(f\): \(f(y) \geq f(x) + \nabla f(x)^T(y-x)\).

3. Statistical Learning & Models

3.1 Setup

We have data \((X, Y) \sim P\), i.i.d. draws. A model \(f_\theta \in \mathcal{H}\) learns a mapping \(X \to Y\).

  • Loss function \(\ell(y, \hat{y})\): measures prediction error.
  • Risk \(R(f_\theta) = \mathbb{E}[\ell(f_\theta(X), Y)]\): expected loss on population.
  • Empirical Risk Minimization (ERM): \(\hat{\theta} = \arg\min_\theta \frac{1}{n}\sum_{i=1}^n \ell(f_\theta(x_i), y_i)\).

3.2 Linear Regression

Model: \(y = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p + \epsilon\)

Loss (L2): \(L(\beta) = \frac{1}{2n}\|X\beta - y\|_2^2\)

Closed form: \(\hat{\beta} = (X^T X)^{-1} X^T y\)

Gradient descent update: \(\beta^{(t)} = \beta^{(t-1)} - \frac{\eta}{n}\sum_i ((\beta^{(t-1)})^T x_i - y_i)x_i\)

3.3 Logistic Regression

Model: \(P[Y=1|X=x] = \sigma(\beta^T x) = \frac{1}{1 + e^{-\beta^T x}}\)

Loss (binary cross-entropy): \(-\sum_i [y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]\)

Decision boundary: \(\beta^T x = 0\)

3.4 Multi-class Classification

Softmax: \(P[Y=k|X=x] = \frac{e^{z_k}}{\sum_j e^{z_j}}\) where \(z = Wx + b\).

Softmax is shift-invariant: adding a uniform offset to logits does not change probabilities.

4. Gradient Descent & SGD

Gradient Descent

Update: \(x_{t+1} = x_t - \eta \nabla f(x_t)\)

\(\eta\) = step size / learning rate.

Stochastic Gradient Descent (SGD)

Use a mini-batch \(B\): \(g(\theta) = \frac{1}{|B|}\sum_{i\in B} \nabla \ell(f_\theta(x_i), y_i)\)

Update: \(\theta_{t+1} = \theta_t - \eta g_t\)

GD as surrogate optimization: Approximate \(f\) by a second-order Taylor model with Hessian \(\frac{1}{\eta}I\), minimize it to get the GD update.

Step Size Trade-off

Small \(\eta\) Large \(\eta\)
Slow progress, many iterations Big progress, but overshooting and zig-zagging
More likely to converge May diverge

5. Adversarial Attacks on ML Models

5.1 Definition

Adversarial example \(x_{\text{adv}} = x_{\text{og}} + \delta\) such that:

  1. Misclassification: \(f(x_{\text{adv}}) \neq f(x_{\text{og}})\)
  2. Proximity: \(\|\delta\| \leq \epsilon\) (small perturbation)

Targeted: \(f(x_{\text{adv}}) = y_{\text{target}}\)  |  Untargeted: \(f(x_{\text{adv}}) \neq y_{\text{og}}\)

5.2 FGSM (Fast Gradient Sign Method)

Linear classifier: \(x_{\text{adv}} = x_{\text{og}} + \epsilon \cdot \text{sign}(w)\)

General nonlinear: \(x_{\text{adv}} = x_{\text{og}} + \epsilon \cdot \text{sign}(\nabla_x J(\theta, x_{\text{og}}, y))\)

One-step method; fast but coarse.

5.3 I-FGSM (Iterative FGSM)

\(x_{i+1}^{\text{adv}} = \text{clip}_{[0,1]}(x_i^{\text{adv}} + \epsilon \cdot \text{sign}(\nabla_x J(\theta, x_i^{\text{adv}}, y)))\)

Multiple small steps with clipping; stronger and finer than FGSM.

5.4 DeepFool

Finds minimal perturbation to cross decision boundary.

Linear: \(x_{\text{adv}} = x_0 - \frac{f(x_0)}{\|w\|_2^2}w\)

Nonlinear: iterate \(x_{t+1} = x_t - \frac{f(x_t)}{\|\nabla f(x_t)\|_2^2}\nabla f(x_t)\)

5.5 Boundary Attack (black-box, decision-based)

Start from an adversarial point; random walk along decision boundary, shrinking toward original.

Needs only the final label; query-hungry.

5.6 Mimicry Attack

Favor attack points from dense regions of legitimate data using KDE:

\(\min_x F(x) = g(x) - \lambda \frac{1}{n}\sum_{i:y_i=-1} K\left(\frac{x-x_i}{h}\right)\)

Subject to \(\text{dist}(x, x_0) < d_{\max}\).

5.7 Kernel Density Estimation (KDE)

\(\hat{f}(x) = \frac{1}{nh}\sum_{i=1}^n K\left(\frac{x-x_i}{h}\right)\)

Bandwidth \(h\) controls smoothness:

  • Small \(h\): spiky, overfits, high variance.
  • Large \(h\): over-smoothed, high bias, hides structure.

6. Adversarial Attacks on LLMs

6.1 Tokenization & Embeddings

LLMs use subword tokenization (BPE, WordPiece). Each token maps to an embedding vector.

Similarity: \(\cos\theta = \frac{e_{\text{cat}}^T e_{\text{dog}}}{\|e_{\text{cat}}\|\|e_{\text{dog}}\|}\)

6.2 Jailbreaks & GCG Attack

Goal: append adversarial suffix so aligned model answers harmful request.

Maximize \(P[\text{"Sure, here is how to..."} | \text{prompt} + \text{suffix}]\).

GCG works in hard-token space using gradient w.r.t. one-hot encodings:

\(\nabla_x \mathcal{L} = \Phi^T \nabla_e \mathcal{L}\)

6.3 Hard vs. Soft Prompts

Hard Prompt Soft Prompt
Form Real, interpretable tokens Continuous embeddings
Optimization Discrete search (GCG, PEZ) Gradient-based
Portability Portable across models Not portable

PEZ (hard prompt learning): Learn prompt \(P\) to match text embedding to target image embedding via CLIP:

\(\min_P \mathcal{L}(P) = 1 - \cos(f(P), g(x))\)

7. Adversarial Defense

Detection

Two-sample hypothesis testing: \(H_0: P = Q\) vs. \(H_1: P \neq Q\).

Limitation: needs a large batch of adversarial examples.

Pre-processing

Transform input to remove perturbations: cropping, rescaling, bit-depth reduction, JPEG, Total Variation Minimization.

Adversarial Training

\(\min_\theta \mathbb{E}_{(x,y)} [\max_{\delta \in S} \ell(f_\theta(x+\delta), y)]\)

Inner max = attack; outer min = defense.

Defensive Distillation

Train student on soft labels from teacher with temperature \(T\).

High \(T\) smooths outputs and reduces adversarial gradients.

Trade-off: Adversarial training is costly and may reduce clean accuracy. Pre-processing can destroy useful detail.

8. Federated Learning (FL)

8.1 Setup

\(K\) clients, each with local data \(D_k\). Server aggregates updates without seeing raw data.

Goal: \(\min_w f(w) = \sum_{k=1}^K \frac{n_k}{n} F_k(w)\)

8.2 FedSGD vs. FedAvg

FedSGD

Each client does 1 local gradient step; server averages.

Equivalent to centralized GD on the union of data.

FedAvg

Each client does \(M\) local SGD steps; server averages parameters.

Fewer communication rounds but client drift on non-IID data.

8.3 Non-IID Data Challenge

With non-IID data and large \(M\), local models drift toward local optima, slowing global convergence.

When \(M = 1\), IID and non-IID results coincide (FedSGD = centralized GD).

8.4 Hyperparameter Trade-offs

Hyperparameter Lower value Higher value
C (client fraction) Cheaper rounds, noisier aggregate Stable aggregate, more computation
M (local updates) More communication, no drift Fewer rounds, client drift on non-IID
B (mini-batch size) Noisy gradients, cheap steps Smooth gradients, costly steps

9. Homomorphic Encryption (HE)

Property: \(f(\text{Enc}(m,k)) = \text{Enc}(f(m),k)\)

Allows server to compute on encrypted data without seeing it.

Trade-off: Strong privacy but very slow and supports limited operations.

Example: \(x + y\) without sharing data

Worker 1 encrypts \(x\), Worker 2 encrypts \(y\). Server computes on ciphertexts. Only key holder decrypts.

But ordinary encryption breaks computation: \(x' + y' \neq \text{Enc}(x+y)\) in general.

10. Data Privacy & Cryptography

Anonymization Isn't Enough

Netflix Prize: linked "anonymous" ratings to IMDb profiles (Narayanan & Shmatikov, 2008).

Cryptography

Alice sends \(m\) to Bob; Eve eavesdrops.

\(C = \text{Enc}(k, m)\), \(m = \text{Dec}(k, C)\).

CIA triad: confidentiality, integrity, availability.
