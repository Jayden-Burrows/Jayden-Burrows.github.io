1. The Machine Learning Landscape

Based on 01_The_Machine_Learning_Landscape.pdf

What is Machine Learning?

Machine learning is the science (and art) of programming computers so they can learn from data. Instead of writing explicit rules, we train a model on examples.

Types of Machine Learning

  • Supervised – training data includes desired solutions (labels). Tasks: classification, regression.
  • Unsupervised – no labels; discover hidden structure (clustering, visualization, dimensionality reduction, anomaly detection, association rules).
  • Semi-supervised – partially labeled data; combine small labeled set with large unlabeled set.
  • Self-supervised – labels generated automatically from unlabeled data (e.g., mask part of an image and reconstruct).
  • Reinforcement learning – an agent interacts with an environment, learns a policy to maximize long-term reward.

Online vs. Batch Learning

  • Batch learning – trained on the full dataset, typically offline; model does not learn after deployment. Retraining needed periodically.
  • Online learning – model updates incrementally with new data (mini-batches). Supports continuous adaptation, out-of-core learning; learning rate controls adaptation speed.

Training / Validation / Testing Sets

  • Training set – used to fit model parameters.
  • Validation set – used to tune hyperparameters and select models (holdout validation).
  • Test set – used only once to estimate generalization error on unseen data.

⚠️ Tuning hyperparameters on the test set causes overfitting to the test set. Always use a separate validation set.

2. Ensemble Learning & Random Forests

Based on 06_Ensemble_Learning_and_Random_Forests.pdf

Voting Classifiers

  • Hard voting – majority vote among classifiers.
  • Soft voting – weighted average based on predicted class probabilities; often performs better.

Bagging vs. Pasting

  • Bagging – sampling with replacement (bootstrap aggregating).
  • Pasting – sampling without replacement.
  • Feature sampling can also be used: random patches (instances + features) and random subspaces (features only).

Random Forest

An ensemble of decision trees, each trained on a random subset of the data (bagging) and often using random feature subsets. Final prediction by majority vote (classification) or averaging (regression).

Boosting

  • AdaBoost – sequentially trains weak learners; misclassified instances get more weight. Predictor weight depends on accuracy: αj = η log((1−rj)/rj).
  • Gradient Boosting – sequentially fits new models to the residual errors of previous models. Learning rate (shrinkage) controls each tree’s contribution.

Stacking

Stacked generalization: train a meta-model (blender) to combine predictions of base models. Use out-of-sample predictions (cross_val_predict) to train the blender.

When to use ensemble methods
Method When to use
Hard voting Balanced classification, multiple strong diverse classifiers
Soft voting Probabilistic models, confidence scores matter
Bagging High variance, overfitting-prone models
Pasting More independent models desired
Random forest High-dimensional, noisy features
AdaBoost Small/medium, low-noise, weak learners
Gradient boosting Medium/large, high predictive power
Stacking Complex, high-dimensional, maximize accuracy

3. Dimensionality Reduction

Based on 07_Dimensionality_Reduction.pdf

Curse of Dimensionality

In high dimensions, data becomes sparse, distance-based methods become less effective, and overfitting risk increases. The required sample size grows exponentially with the number of dimensions.

Example: In a unit square, average distance between two random points ≈ 0.52; in a 1,000,000‑dimensional hypercube, it’s ≈ 408.25.

PCA (Principal Component Analysis)

  • Identifies the hyperplane that lies closest to the data and preserves the most variance.
  • Principal components are obtained via Singular Value Decomposition (SVD); matrix V contains the principal components.
  • Explained variance ratio – proportion of variance captured by each PC. Use explained_variance_ratio_ in scikit‑learn.
  • Projection: Xd-proj = X · Wd (first d columns of V).
  • Inverse transform: Xrecovered = Xd-proj · WdT (reconstruction error).
  • Variants: Randomized PCA (faster when d ≪ n), Incremental PCA (mini-batches).

Random Projection

Uses a random linear transformation to project data. Surprisingly preserves distances well (Johnson–Lindenstrauss lemma). Works well for sparse, very high-dimensional data. Trades accuracy for speed.

Manifold Learning

  • LLE (Locally Linear Embedding) – nonlinear method. First finds how each instance relates to its nearest neighbors; then finds a low‑dimensional representation preserving these local relationships.
  • Other techniques: MDS, Isomap, t‑SNE (visualization), LDA (supervised).

📉 Dimensionality reduction can speed training, but benefits depend on the dataset. Most useful for noisy, small, or highly correlated data.

4. Neural Networks

Based on 09_Introduction_to_Artificial_Neural_Networks.pdf and backpropagation_notes.pdf

Threshold Logic Unit (TLU) & Perceptron

  • TLU – computes linear function z = wTx + b, then applies a step function (Heaviside or sign).
  • Perceptron – one or more TLUs in a single layer, fully connected to inputs. Cannot solve XOR.

Multi-Layer Perceptrons (MLPs)

  • Contain input, hidden, and output layers. Can solve XOR and complex problems.
  • Activation functions – introduce nonlinearity. Common: Sigmoid, Tanh, ReLU.
  • Without activation functions, deep networks reduce to a single linear model.

Backpropagation (High-Level)

Backpropagation = automatic differentiation + gradient descent. It efficiently computes gradients of the loss w.r.t. all parameters using the chain rule, working backward from the output layer. Then parameters are updated via gradient descent: w ← w − η · ∂l/∂w.

Chain rule (example):

f(x) = (x² + 2x)² → let u = x² + 2x, f(u) = u².

∂f/∂x = ∂f/∂u · ∂u/∂x = 2u · (2x + 2) = 2(x² + 2x)(2x + 2).

Transfer Learning

Reuse lower-layer features learned on a similar task. Deep architectures naturally support transfer learning, which is especially useful when target data is limited.

Hyperparameter Tuning Guidelines

  • Hidden layers: start with 1–2; increase depth as task complexity grows. Deep nets are more parameter‑efficient.
  • Neurons per layer: equal‑sized hidden layers often work well; increase until overfitting appears.
  • Learning rate: one of the most important. Optimal often ~half of maximum (divergence) rate.
  • Batch size: large batches improve hardware efficiency; small batches may generalize better.
